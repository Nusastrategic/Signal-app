# Forum-Edge
This is Forum Edge Early Access by Nusastrategic (the link is in html view but the website link is android app version)
Ever sat in a forum or seminar and had a question in your head but couldn't quite shape it into something sharp and clear before the moment passed?

That happens to me more than I'd like to admit. So I started building a small tool to fix that for myself.

Forum Edge is a fully offline app for structuring critical questions and practicing argumentation. You can use it to prep before events, simulate debate scenarios, or just train yourself to think more precisely under pressure.

It's a personal project I've been working on quietly, and I'm opening it up for free early access until June 21.
